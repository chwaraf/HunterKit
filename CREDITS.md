### Low-ammo voice clips

Short spoken warnings, rendered for this addon with a text-to-speech generator
(a British-accented voice, auditioned and picked by the author) and then trimmed
at the detected silence gaps with `ffmpeg`. They are Ogg Vorbis rather than MP3
because the Classic-era client's MP3 decoder cut the last word off.

| File | Says | Used when |
|------|------|-----------|
| `voice_lowarrows.ogg` | "Low arrows!" | arrows are below the warning threshold |
| `voice_lowammo.ogg` | "Low ammo!" | bullets are below the warning threshold |
| `voice_noarrows.ogg` | "No arrows!" | the arrow slot is empty |
| `voice_noammo.ogg` | "No ammo!" | the bullet slot is empty |

Voice warnings are **off by default** and are the only sounds the low-ammo
feature can make — it never plays a Blizzard sound. The clips are released by
the author under the same **CC0 1.0** terms as the pews; if you redistribute
HunterKit commercially, re-check the terms of the speech generator they were
rendered with.

### Bring-your-own audio

Users may drop their own `pew-N.ogg` files into `Media/` to replace the bundled
ones, provided the replacement audio is licensed for redistribution (CC0, CC-BY,
or public domain). If you ship a CC-BY file, keep its attribution here and in the
README. Replacing a voice clip works the same way — the four filenames above are
read straight out of `Media/`.

## Texture assets (`Media/*.png`)

Eighteen reticle textures back the Sniper Mark — six shapes per range state
(IN RANGE / TOO CLOSE / OUT OF RANGE), plus the three restored classic marks
(`crosshair.png`, `crosshair-x.png`, `crosshair-outline.png`).

They are generated artwork, produced for this addon and post-processed by the
author's own tools: `tools/build_mark_art.py` luminance-keys each image (black →
transparent, mark → opaque white), crops it to the mark, squares it and resizes
it, and `tools/tga_to_png.py` then converts the result to PNG losslessly. White
art on alpha is deliberate — it lets the in-game `SetVertexColor` tint each mark
with its state colour. No third-party texture, icon or font is used, and the
marks contain no Blizzard artwork. They are released under **CC0 1.0**.

Everything else the addon draws is Blizzard's own art, **referenced in place
rather than bundled**, which is the normal addon convention — nothing is
extracted, copied or redistributed:

| Where | Blizzard file |
|---|---|
| Feed Pet button | the Feed Pet spell's own icon (resolved from spell 6991), `134400` as the "?" fallback |
| Pet Mend marker | the Mend Pet spell's icon, `Interface\Icons\Ability_Hunter_MendPet` as fallback |
| Passive-pet alert | `Interface\Icons\Ability_Seal` |
| Threat warning | `Interface\Icons\Ability_Physical_Taunt`, `Interface\Icons\Ability_Hunter_FeignDeath` |
| Low ammo warning | the equipped projectile's own icon, with `Interface\Icons\INV_Arrow_02` / `INV_Ammo_Bullet_03` as fallbacks and `Interface\Buttons\UI-GroupLoot-Pass-Up` as the red X |
| Sonar rings / urgent mend ring | `Interface\Cooldown\star4` |
| Bars, borders, the nameplate-style plate | `Interface\Buttons\WHITE8x8`, `Interface\Tooltips\UI-Tooltip-Background` |

Those remain Blizzard's property.

## Data: the pet-food table (`FoodDB.lua`)

`HK.FOOD_BY_TYPE` — the item-ID → diet mapping (Meat / Fish / Bread / Cheese /
Fruit / Fungus) that lets the Feed Pet button know what a given pet can eat — is
**adapted from the vanilla food database published with Fizzwidget's
Feed-O-Matic** (original author Gazmik Fizzwidget; the community fork is
maintained as `feed-o-matic`). This is reference *data*: item IDs and their diet
categories. No Feed-O-Matic code is copied, and HunterKit does not depend on,
load, or embed the addon.

Attribution is given here in good faith. Note that Feed-O-Matic's original was
published as open source while its current Classic/WotLK distributions are
marked "All Rights Reserved", so if you redistribute HunterKit commercially,
confirm the food list's terms with the current maintainer first. Diet types and
item IDs are game facts rather than creative expression, but that is a judgement
for you to make, not one to inherit silently from this file.

The one-click secure Feed Pet *technique* (a spell button whose attributes are
refreshed out of combat) is the same approach Feed-O-Matic and LibSpellButton
use; HunterKit implements it independently.

## Techniques referenced (no code or data copied)

For completeness, the community work whose behaviour informed these features.
Each is re-implemented here from scratch against the client API:

| Feature | Informed by |
|---|---|
| Sniper Mark range states | the community range WeakAuras (`IsSpellInRange` + `CheckInteractDistance`) |
| Low ammo warning | Kals' ClassicAmmoCount (configurable threshold), the "3/2/1 stacks left" WeakAuras |
| Auto Shot timer / weave bar | the popular Auto Shot WeakAuras and Classic hunter weaving guides |
| Pet aggro warning | what LibThreatClassic2 / Details TinyThreat *do* — deliberately **not** how: HunterKit reads the threat API Blizzard reinstated in 1.13.5 instead of parsing the combat log, so it needs no coefficient tables and no addon comms |
| Macro library | the standard community hunter macro set (Feign Death, trap drops, mouseover pet send, two-mob weave) |
